## Campaign 1: Google Play App Install Campaigns

### Configuration

**Campaign Type:** App Install - App Campaigns

**Targeting:**

```
Audiences:
├── In-market audiences: "Beauty & Personal Care", "Health & Fitness"
├── Affinity audiences: "Beauty Enthusiasts", "Natural/Organic Products", "Wellness"
├── Interest segments: "Natural beauty", "Skincare", "Wellness lifestyle"
├── Demographics: 
│   ├── Gender: Female (primary), All (secondary)
│   ├── Age: 25-54 (primary), 18-64 (secondary)
│   └── Parental Status: Parents (secondary)
│
└── Placements: Google Play, YouTube, Search, Display Network
```

**Bid Strategy:** Target Install Cost (tCPI) 
- Initial bid: $2-3 per install
- Adjust based on performance
- iOS typically higher ($4-5)
- Android typically lower ($2-3)

**Daily Budget:** $100-150/day ($2,800-4,500/month)

### Ad Copy Focus on VIP Membership

**Headline Priority Order:**
1. "Get 15% Off Every Purchase" (direct savings)
2. "Free Shipping on All Orders" (value prop)
3. "VIP Access - Only $19.99/Month" (price transparency)

**Key Messages:**
- **Savings:** "Save $50+ per month with 15% VIP discount"
- **Free Shipping:** "Free shipping on all orders for VIP members"
- **Exclusivity:** "Early access to new products"
- **Value:** "Premium skincare at half the price"
- **Social Proof:** "Trusted by 10,000+ customers"

### Expected Performance Targets

| Metric | Target | Benchmark |
|--------|--------|-----------|
| Cost Per Install | $2.50 | Industry avg $3-5 |
| Install Volume (Month 1) | 500-800 | 50+ daily |
| Click-Through Rate | 3-5% | 2-4% typical |
| Conversion Rate (Install→VIP) | 8-12% | 5-10% typical |
| VIP Subscribers from Campaign | 40-100 | From installs |
| Revenue from VIP (Month 1) | $800-2,000 | 40-100 subs × $19.99 |

## Conversion Rate Targets

### Install to VIP Conversion Funnel

```
Google Ads Traffic
    ↓
1,000 app installs

    ↓ (30% browse products)

    ↓ (25% add to cart)
```

## Measurement & KPIs

### Key Performance Indicators

| Metric | Target | Action If Below |
|--------|--------|-----------------|
| Cost Per Install | $2.50 | Optimize creatives, adjust bids |
| Install Volume | 50+/day | Increase budget, expand targeting |
| D1 Retention | 40%+ | Improve onboarding, reduce friction |
| VIP Conversion Rate | 1%+ | Increase in-app VIP prompts, better creatives |
| VIP Revenue | $200+/month | Scale budget if CAC < LTV |
| Click-Through Rate | 3%+ | A/B test ad copy, refresh creatives |
| View-Through Rate (Video) | 25%+ | Shorten video, improve hook |

### Dashboard to Monitor Weekly

```
Google Ads Performance:
├── Total Spend: Actual vs Budget
├── Install Volume: Trend analysis
├── Cost Per Install: Weekly average
├── Top Performing Creatives: Engagement rates
├── Top Performing Keywords: CTR, CPA
└── Campaign Status: Paused/Running/Optimizing

App Analytics:
├── Daily Active Users (DAU)
├── Install Retention (D1, D7, D30)
├── VIP Signups: Weekly count
├── VIP Conversion Rate: % of installs
├── First Purchase Rate: % of DAU
└── Average Order Value (AOV)

Revenue Impact:
├── VIP Subscription Revenue: Weekly
├── Average Customer LTV: Cohort basis
├── CAC Payback Period: Months to break even
└── ROI: Revenue ÷ Ad Spend
```
