Send Your First Newsletter
──────────────────────────
1. Create campaign:
   curl -X POST http://localhost:3000/api/admin/campaigns \
     -H "Content-Type: application/json" \
     -d '{"name":"My Newsletter","subject":"News","templateId":"newsletter"}'

2. Send campaign (replace {id} with campaign ID from response):
   curl -X POST http://localhost:3000/api/admin/campaigns/{id}/send \
     -H "Content-Type: application/json" \
     -d '{"filterType":"newsletter"}'

Send Promotional Email
──────────────────────
curl -X POST http://localhost:3000/api/admin/promotions/send \
  -H "Content-Type: application/json" \
  -d '{"title":"Sale!","description":"20% off!","code":"SALE20"}'

  ⚙️  EMAIL PROVIDER SETUP
════════════════════════════════════════════════════════════════════════════════

Option A: Gmail (Best for Development)
─────────────────────────────────────
1. Go to https://myaccount.google.com/apppasswords
2. Select "Mail" and "Windows Computer"
3. Google generates a 16-character password
4. Add to .env:
   EMAIL_PROVIDER=smtp
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_USER=your-email@gmail.com
   SMTP_PASSWORD=your-app-specific-password

Option B: SendGrid (Best for Production)
──────────────────────────────────────
1. Create SendGrid account at https://sendgrid.com
2. Get API key from https://app.sendgrid.com/settings/api_keys
3. Add to .env:
   EMAIL_PROVIDER=sendgrid
   SENDGRID_API_KEY=SG.your_api_key_here

════════════════════════════════════════════════════════════════════════════════
  🆘 QUICK TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Emails Not Sending?
  1. Check .env configuration
  2. Verify email provider credentials
  3. Run: curl -X POST http://localhost:3000/api/email/test
  4. Check server console for errors
  5. See EMAIL_MARKETING_GUIDE.md troubleshooting section

Template Issues?
  1. Verify template file exists in /templates/emails/
  2. Check template name matches exactly
  3. Ensure variables use {{variableName}} format
  4. Test with /api/email/test endpoint

Connection Problems?
  1. Ensure server is running: npm start
  2. Check port 3000 is available
  3. Verify no firewall is blocking
  4. Check email provider isn't rate limiting
